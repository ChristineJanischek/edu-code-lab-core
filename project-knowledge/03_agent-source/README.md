## Auswertung

Die Quelle führt schrittweise durch Problemklärung, Agentenarchitektur, GitHub als
Lernwerkstatt, UI, React/TypeScript, Backend/API, didaktischen Tutor, neutrale
LLM-Adapter, RAG, Datenbank, Wissensgraph, sichere Codeausführung, Prompt-Injection-
Schutz, Evaluation und Produktreife.

Die PDF ist die mobile Lesefassung; die DOCX bleibt die bearbeitbare Primärfassung.
Änderungen an der didaktischen Grundlage werden hier versioniert und nicht aus dem
Share-Link automatisiert abgeleitet.
